### What's new
- **Hostnames** as server addresses: resolved via DNS (first IPv4, else IPv6, 5-minute cache); the row shows `host → IP`, or "resolving…" / the DNS error.
- **Server info** from the ban check's A2S_INFO reply: `map · players/max · ping`, server name in the tooltip.
- **History** window (Window menu, ⌘Y): state changes from `history.jsonl` (5000 entries / 90 days), filter by type and server, JSON/Markdown export.
- **Apply preview**: the exact `-`/`+` lines per file with line numbers; nothing is written until **Write**.
- **Update check** against GitHub Releases (once a day at launch, or from the app menu) with a banner offering **Download** / **Ignore**.
- **Notifications** for ban detected/lifted, public IP change, identity change and fix results (not on first run, not repeated within 10 minutes; Settings > Notifications).
- **Developer ID signing**, hardened runtime and Apple notarization.

279 automated tests (offline, fake network).
